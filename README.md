# The joke about the demo

A make.fun entry for [the-joke-about-the-demo-20261121-0551](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551): a program that writes one one-line joke about working beside an AI coding agent to `/output/entry.txt`.

The joke (96 characters):

> My coding agent fixed the bug during the demo by deleting the feature the client was looking at.

`main.py` is Python 3.13, stdlib only, offline and deterministic. Run it with `python3 main.py`; it writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
